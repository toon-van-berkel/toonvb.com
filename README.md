## About

**toonvb.com** is my personal portfolio and digital playground.

It brings together the projects I build, the research I conduct and the ideas I experiment with. The site itself is also an ongoing project: designed and developed from scratch with an emphasis on creating interfaces that feel clear, polished and intentional.

The portfolio focuses on four core principles:

- **Visual clarity** — interfaces should communicate before they need explanation.
- **Usability** — interactions should feel natural and predictable.
- **Performance** — speed and responsiveness are part of the experience.
- **Accessibility** — the web should work for as many people as possible.

## Built with

| Technology | Purpose |
| --- | --- |
| **SvelteKit** | Application framework |
| **TypeScript** | Type-safe application logic |
| **SCSS** | Styling and design system |
| **Vite** | Development and build tooling |
| **pnpm** | Package management |

No UI framework is used for the visual design. Components and styling are built specifically for the portfolio.

## Development

### Requirements

- Node.js
- pnpm

### Install

```bash
pnpm install
```

### Start development server

```bash
pnpm dev
```

### Production build

```bash
pnpm build
```

### Preview production build

```bash
pnpm preview
```
